# Feedback & Support for Smart Presentations

Thank you for your interest in Smart Presentations! This document provides guidelines for providing feedback and getting support.

## Code of Conduct

By participating in this project, you agree to abide by our Code of Conduct. Please be respectful and considerate of others.

## Getting Help

If you need help using Smart Presentations:

1. **Join our Discord Community** for real-time support and discussion
2. **Check the documentation** in the README for setup and usage instructions
3. **Review existing issues** to see if your question has already been answered

## Providing Feedback

We'd love to hear from you! Here's how you can share your feedback:

- **Feature requests**: Share what features would make Smart Presentations better for you
- **Bug reports**: Report any issues you encounter with detailed reproduction steps
- **General feedback**: Let us know what you like, dislike, or want to see improved

## Reporting Bugs

If you find a bug or issue:

1. Check if it already exists in our [Issues](https://github.com/smartpresentations/smart-presentations/issues)
2. If not, create a new issue with:
   - A clear and descriptive title
   - Detailed steps to reproduce the bug
   - The expected behavior vs. actual behavior
   - Any relevant screenshots or error messages

## Questions?

If you have questions or need help, reach out via:

- **Discord**: https://discord.gg/fsMHMhAHRV
- **Issues**: https://github.com/smartpresentations/smart-presentations/issues

Thank you for helping make Smart Presentations better for everyone!
